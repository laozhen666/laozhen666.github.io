PHP文件包含(重点伪协议

2026-10-15

文件包含的本质

代码复用
并行开发
模块化
增加移植性

1.include和eval的区别

include和eval一样，都不是函数，都是语言结构，无法通过配置文件函数禁用来禁用

include 后面跟 一个路径，表示要执行的php文件的路径 读取路径中文件内容后，然后执行里面的php代码
而eval 后面跟 php的代码，表示要执行的php代码

php的常见文件包含函数、语言结构

include 仅仅是包含这个文件，如果文件不存在，那么也没啥大不了了，继续执行后面代码

require 必须包含好这个文件，如果没包含好，就不执行了，报错

include_once 包含一次 遇到错误继续执行
require_once 成功包含一次，遇到错误停止

include “flag.php”;

文件包含漏洞，是指，通过文件包含时，包含的内容我们用户可控

一些协议概念我就不介绍了，自己查去

2.file协议

不写协议名字，就默认认为是file协议

相对路径和绝对路径

上层目录特性

1 每个目录都有上层目录
2 根目录的上层目录是根目录本身

/var/www/html/../../../ => / 目录

/var/www/html/../../../../../../../../../../ => / 目录 上溯

比如说某个flag在根目录里边，但是你不知道根目录在哪里，你就可以一直上溯

3.php目录整理特性

/var/www/html/../flag.php

/var/www/html/flag.php

就是说如果你写成第一行，那样就算文件里没有ctf这个文件，他也不会进行报错，他会转换成第二行那种形式

4.三元表达式

A?B:C

如果A成立，返回B的结果，否则返回C的结果

5 .http协议

配合文件包含，可以读取远程的php代码并在本地执行，实现了最终RCE的效果

<?php

include "https://baidu.com/robots.txt";

?>

然后再用浏览器访问这个PHP文件，比如说这个PHP文件叫做my 2，就在本地访问这个my 2就可以了127.0.0.1/my2.php

6 .ftp协议

默认21端口，进行文件传输的协议

7 .php协议(重要)

php://input

<?php

include "php://input";

?>

这里就相当于输入一个代码，比如说它包含了一个这个PHP input，你可以抓包直接使用PHP代码进行重发，然后它就会直接显示结果

注意这个输入，它是按照文本文档处理的，你想执行PHP代码就得按照PHP格式写

php://filter

举一个例子

/?file=php://filter/write=convert.base64
-decode/resource=1.php

这个就是将某个文件写入，然后进行一个b64编码，写进1.PHP文件里，然后配合的就是输入一个命令，然后进行一个b64编码，进行一个rce，一般题目有两个请求头

具体的玩法可以查看PHP中文手册，上面有很多玩法

data协议

他有个固定的格式
data://text/plain

ctfer.com:8080/?file=data://text/plain,<?php phpinfo();?>

比如说我可以这样进行书写，直接执行一个php代码，data协议相比于其他协议简单很多

更多玩法查阅php中文手册
